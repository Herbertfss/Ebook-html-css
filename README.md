## 📖 Sobre o Ebook

Um ebook **gratuito e completo** para dominar HTML e CSS do básico ao avançado. Com exemplos práticos, exercícios e projetos reais, este guia foi desenvolvido para ajudar iniciantes a se tornarem profissionais do desenvolvimento web.

### 🎯 O que você vai aprender

- ✅ **HTML Semântico** - Estrutura correta e acessível
- ✅ **CSS Moderno** - Flexbox, Grid e animações
- ✅ **Responsividade** - Mobile First e Media Queries
- ✅ **Projetos Práticos** - Landing page, cards interativos
- ✅ **Boas Práticas** - Código limpo e organizado
- ✅ **Publicação** - Deploy gratuito com GitHub Pages

## 📂 Estrutura do Projeto
```
Ebook-html-css/
│
├── index.html # Página principal do ebook
├── css/
│ ├── base.css # Reset e variáveis CSS
│ ├── layout.css # Estrutura de layout
│ ├── components.css # Componentes UI
│ └── dark-mode.css # Tema escuro
├── js/
│ ├── main.js # Funcionalidades principais

```


## 🎨 Funcionalidades

- 🌓 **Dark Mode** - Alternância entre tema claro/escuro

- 🎯 **Navegação por Capítulos** - Sumário interativo

- 📤 **Compartilhamento** - Compartilhe nas redes sociais

## 📖 Como Usar

### Leitura Online
Basta acessar: [https://herbertfss.github.io/Ebook-html-css/](https://herbertfss.github.io/Ebook-html-css/)

### Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/Herbertfss/Ebook-html-css.git
```
2. Abra o arquivo index.html no seu navegador

3. Ou use o Live Server no VS Code para melhor experiência

## Personalizar
1. Edite o conteúdo no index.html

2. Modifique as cores no css/base.css (variáveis CSS)

3. Adicione mais capítulos seguindo o padrão existente
