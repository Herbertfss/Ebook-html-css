1. Introdução ao HTML

HTML (HyperText Markup Language) é a linguagem padrão para criação de páginas web. Ela fornece a estrutura básica dos sites, que é então estilizada pelo CSS e tornada interativa pelo JavaScript.

O que você vai aprender neste capítulo:

  • O que é HTML e como funciona
  • Estrutura básica de um documento HTML
  • Tags, elementos e atributos
  • Seu primeiro código HTML
HTML 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Minha Primeira Página</title>
</head>
<body>
    <h1>Olá, Mundo!</h1>
    <p>Este é meu primeiro site HTML.</p>
</body>
</html>
Dica Profissional: Sempre use a declaração <!DOCTYPE html> no início do documento para garantir que o navegador renderize a página em modo padrão.

2. Estrutura e Semântica HTML

A semântica HTML é fundamental para criar sites acessíveis, otimizados para SEO e de fácil manutenção. As tags semânticas descrevem o significado do conteúdo, não apenas sua aparência.

Tags Semânticas Principais:

<header>

Cabeçalho da página ou seção

<nav>

Navegação principal

<main>

Conteúdo principal único

<article>

Conteúdo independente

<section>

Grupo temático de conteúdo

<aside>

Conteúdo complementar

Atenção: Evite usar divs para tudo! Prefira tags semânticas sempre que possível para melhorar a acessibilidade e o SEO.

3. Formulários e Tabelas

Formulários são essenciais para interagir com usuários, enquanto tabelas organizam dados de forma estruturada.

Exemplo de Formulário Moderno:

HTML 
<form action="/enviar" method="POST">
    <label for="nome">Nome:</label>
    <input type="text" id="nome" name="nome" required>
    
    <label for="email">E-mail:</label>
    <input type="email" id="email" name="email" required>
    
    <label for="mensagem">Mensagem:</label>
    <textarea id="mensagem" name="mensagem" rows="4"></textarea>
    
    <button type="submit">Enviar</button>
</form>
Exercício Prático: Crie um formulário de cadastro com campos para nome, email, senha e data de nascimento. Use validação HTML5!

4. Fundamentos do CSS

CSS (Cascading Style Sheets) é a linguagem que dá vida ao HTML, controlando cores, fontes, espaçamentos, posicionamento e muito mais.

Três Formas de Aplicar CSS:

Inline

Direto no elemento HTML usando o atributo style

<p style="color: red;"></p>
Interno

Dentro da tag <style> no <head>

<style> p { color: red; } </style>
Externo

Arquivo .css separado (RECOMENDADO)

<link rel="stylesheet" href="style.css">
Boa Prática: Sempre use CSS externo para projetos reais. Isso mantém o código organizado, reutilizável e com melhor desempenho.

5. Box Model e Layout

O Box Model é fundamental para entender como os elementos HTML ocupam espaço na página. Todo elemento é uma caixa retangular com propriedades que afetam seu layout.

Componentes do Box Model:

  • Content - O conteúdo real do elemento
  • Padding - Espaço interno entre o conteúdo e a borda
  • Border - A borda ao redor do padding
  • Margin - Espaço externo entre elementos
CSS 
/* Exemplo de Box Model */
.caixa {
    width: 300px;
    padding: 20px;      /* Espaço interno */
    border: 2px solid #333; /* Borda */
    margin: 15px;       /* Espaço externo */
    box-sizing: border-box; /* Inclui padding e border na largura total */
}
Dica Essencial: Use box-sizing: border-box em todos os elementos para tornar o layout mais previsível!

6. Flexbox - Guia Completo

Flexbox revolucionou a criação de layouts CSS, permitindo alinhamento e distribuição de espaço de forma eficiente, mesmo quando os tamanhos dos itens são dinâmicos.

Propriedades do Container Flex:

display: flex

Define o container como flexível

flex-direction

Define direção (row, column)

justify-content

Alinhamento horizontal

align-items

Alinhamento vertical

CSS 
.container-flex {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 20px;
    flex-wrap: wrap;
}

.item-flex {
    flex: 1; /* Cresce igualmente */
    min-width: 200px;
}
Desafio: Crie uma navbar responsiva usando Flexbox com logo no centro e links à direita!

7. CSS Grid - Layout Moderno

CSS Grid é o sistema de layout bidimensional mais poderoso do CSS, perfeito para criar layouts complexos e responsivos em duas dimensões (linhas e colunas).

Conceitos Fundamentais:

CSS 
.grid-container {
    display: grid;
    grid-template-columns: repeat(3, 1fr); /* 3 colunas iguais */
    gap: 20px;
    padding: 20px;
}

.item-destaque {
    grid-column: span 2; /* Ocupa 2 colunas */
    grid-row: span 1;
}

/* Layout responsivo automático */
.grid-automatico {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
}
Dica Pro: Combine Flexbox (para componentes) com Grid (para layout da página) para o melhor dos dois mundos!

8. Responsividade e Mobile First

Mais de 50% do tráfego web vem de dispositivos móveis. Criar sites responsivos não é mais opcional - é obrigatório!

Media Queries Essenciais:

CSS 
/* Mobile First - Base para mobile */
.container {
    padding: 10px;
}

/* Tablet */
@media (min-width: 768px) {
    .container {
        max-width: 720px;
        margin: 0 auto;
    }
}

/* Desktop */
@media (min-width: 1024px) {
    .container {
        max-width: 960px;
    }
    .grid {
        display: grid;
        grid-template-columns: repeat(3, 1fr);
    }
}
Mobile First: Comece pelo design mobile e depois melhore para telas maiores! Isso garante performance e melhor experiência.

9. Animações e Transições

Animações trazem vida ao seu site! Com CSS você pode criar desde micro-interações até animações complexas sem JavaScript.

Transitions vs Animations:

Transitions

Mudanças suaves entre estados (hover, focus)

transition: all 0.3s ease;
Animations

Sequências complexas e loops

animation: fadeIn 2s infinite;
CSS 
/* Transição suave */
.botao {
    transition: transform 0.3s ease, background 0.3s;
}
.botao:hover {
    transform: scale(1.05);
    background: #4a6fa5;
}

/* Keyframe Animation */
@keyframes fadeInUp {
    from {
        opacity: 0;
        transform: translateY(30px);
    }
    to {
        opacity: 1;
        transform: translateY(0);
    }
}

.elemento {
    animation: fadeInUp 0.6s ease-out;
}

11. Projeto Prático 2 - Cards Interativos

Crie cards interativos para mostrar produtos, serviços ou posts do blog com efeitos modernos.

CSS 
.card {

    overflow: hidden;

    transition: transform 0.5s ease;

.card:hover .card-image img {
    transform: scale(1.1);

.card-content {
    padding: 24px;
}

    display: inline-block;
    padding: 12px 24px;

    color: white;
    border-radius: 8px;

12. Publicando seu Site

Seu site está pronto! Agora vamos publicá-lo gratuitamente usando GitHub Pages.

Passo a Passo:

  1. Crie um repositório no GitHub (ex: meu-site)
  2. Envie seus arquivos (index.html, css/, js/) para o repositório
  3. Ative o GitHub Pages: Settings > Pages > Branch main
  4. Acesse seu site em: https://seuusuario.github.io/meu-site/
Git Commands 
# Comandos para publicar
git init
git add .
git commit -m "Meu primeiro site"
git branch -M main
git remote add origin https://github.com/seuusuario/meu-site.git
git push -u origin main
